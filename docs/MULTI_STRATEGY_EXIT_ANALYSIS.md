# 多策略与进出场机制深度分析

> 研究问题：有了 signal 之后，如何确定买入卖出？见好就收还是持有到负面信号出现？
> quantlab 要做多策略组合，还差哪些 feature？
> 日期：2026-09-30。证据来源：quantlab 代码盘点（file:line）+ 学术/业界文献。

---

## TL;DR

1. **"如何卖出"没有普适答案——它由策略收益的自相关结构决定。** Kaminski & Lo (2014) 是承重结论：动量型收益下止损有价值、应"截断亏损、让利润奔跑"；均值回归型收益下止损反而摧毁价值、应"到目标就收、超时强平"。两种看似相反的规则其实是同一条：**当继续持仓的条件期望不再为正时就退出**。
2. **quantlab 的退出条件侧其实已经相当完整**（exit-role 组合器、stop/trailing/target/ATR/max-holding 全套），真正的缺口在**仓位形状侧**：不能分批止盈、不能加仓、不能动态移动止损、filter 不能触发退出、信号强度无法影响仓位大小。
3. **多策略是 quantlab 完全空白的一层**：一次 run = 一个策略一本账；sleeve 是按标的分的不是按策略分的；没有资金分配、没有组合净值、没有策略间相关性分析。specs 里没有任何多策略 roadmap。
4. 建议路线：**先做"组合分析层"（纯离线组合多个已有 run 的净值，零引擎改动，拿到 √N 的夏普改善证据），再做"仓位生命周期增强"（三重屏障统一抽象），最后才做真正的多策略同账本执行。**

## 第一部分：quantlab 现状盘点（代码证据）

### 1.1 信号如何变成买入（已完整）

规则 → `SignalEvent(date, direction)` → 按 (symbol, date) 组合 → `Decision` → `ExecutionSimulator`。

- 三种 role：`entry` / `exit` / `filter`（`strategy/spec.py:35-46`）。只有 entry 组件参与入场（`compose.py:220-229`）；filter 只开门、不触发（`compose.py:212-215, 250`）。
- 组合器 `all | any | majority | weighted` 各带 `combine_window_days`（信号在触发后 N 个交易日内视为"活跃"）。
- 入场需过引擎侧闸口：未持仓（**禁止加仓**，`engine.py:875-878`）、`max_positions` 槽位、`cooldown_days`、现金充足。

### 1.2 退出机制（比预想完整）

`EXIT_REASONS`（`execution/config.py:36-43`）：`signal | stop_loss | take_profit | trailing_stop | max_holding | end_of_window`。

每日 bar 内的固定优先序（`engine.py:712-796`）：

1. 昨收决策在今日开盘成交（先卖后买）
2. **保护性退出**（用本 bar high/low 判定，同 bar 歧义一律按止损处理）：
   - 固定止损 `stop_loss_pct`；**ATR 止损**在入场时与固定止损取更紧者合并（`engine.py:511-537`）
   - 移动止损 `trailing_stop_pct`（基于 `best_close` 棘轮）
   - 固定止盈 `take_profit_pct`（跳空时故意按目标价成交，保守）
   - `max_holding_days`（按标的自己的 bar 计数）
3. **信号退出**：exit-role 决策，受 `min_holding_days` 抑制（保护性退出不受）
4. 信号入场最后执行（先腾出槽位和现金）

关键设计细节：
- **exit 也有完整组合器栈**：`exit_logic` + `exit_threshold` + 权重/invert，所以"3 个动量规则中 2 个转空才退出"这类复合退出条件**今天就能表达**。
- **filter 不能关门困住持仓**（`compose.py:13-16`）——filter 只 gate 入场。这是深思熟虑的设计，但也意味着"宏观转空时强制退出"表达不了。
- **"持有到反面信号"可以表达**：`macd-crossover` 声明 `roles=("entry","exit")`，作为 exit 组件即可；legacy 单模型路径默认就是这个形态。

## 第二部分：买入之后如何卖出——文献证据

### 2.1 核心结论：退出问题本质是自相关问题

**Kaminski & Lo, "When Do Stop-Loss Rules Stop Losses?" (J. Financial Markets, 2014)** 推导了"止损溢价"：

- 收益 i.i.d.（随机游走）→ 止损**不增加**期望收益，只改变分布形状 + 白花手续费
- 收益**正自相关**（动量）→ 止损**有价值**：今天的亏损预测明天的亏损，砍仓值得付费
- 收益**负自相关**（均值回归）→ 止损**摧毁价值**：今天的亏损预测反弹，止损恰好强制你在反弹前认亏

这一条恒等式统一了几乎所有业界关于退出的经验法则。

### 2.2 "见好就收" vs "持有到负面信号"——取决于策略类型

**趋势/动量：不对称退出，绝不设止盈。**
- 趋势策略的收益来源是 P&L 分布的**正偏度**：大量小亏 + 少数巨赢。任何封顶赢家的规则（固定止盈、常规分批止盈）砍掉的正是养活整个策略的右尾。
- 标准做法：信号翻转退出 或 ATR/Chandelier 移动止损（k≈2–3×ATR），快速截断亏损。
- Clare, Seaton, Smith & Thomas (2013) 的细微发现：在均线趋势规则上**再叠**止损几乎无益——趋势规则自己的翻转已内嵌动量退出，额外止损只是增加换手。**对趋势系统，选好的信号退出 ≈ 最优移动止损。**
- 处置效应（Odean 1998 等）：人类天然做反——过早卖赢家、死扛亏损（兑现盈利的频率是亏损的 ~1.5 倍，且卖掉的赢家随后跑赢留下的输家）。机械化不对称退出赚的正是这个行为偏差的钱。**有利可图的规则在心理上是痛苦的，这不是 bug 而是 alpha 来源。**

**均值回归：到目标就收 + 时间止损 + 宽幅灾难止损。**
- 边际是**收敛型**的、有限大的、半衰期衰减的。价格回到均值后继续持有的期望 ≤ 0，而右尾藏着"永不回归"的 LTCM 式灾难。
- Cesar Alvarez 的系统测试：MR 中稳定有效的退出只有两种——**止盈目标和时间止损**。
- Ernie Chan：硬止损系统性地伤害 MR 回测，因为它恰好在模型说"该持有甚至加仓"的点强制退出。诚实的折中：**宽幅灾难止损 + 更小仓位 + 时间止损 + regime 监控**。

**综合矩阵（同一规则在相反自相关结构上的两种应用）：**

| | 亏损单 | 盈利单 |
|---|---|---|
| 趋势/动量 | 快砍（止损/信号翻转） | 让它跑（移动止损；不设目标） |
| 均值回归 | 容忍（宽幅灾难止损 + 时间止损） | 快收（回到均值即止盈） |

### 2.3 退出机制完整分类

| 机制 | 典型用途 | 关键注意 |
|---|---|---|
| 反向信号退出 | 趋势 | 亏损无界；震荡中回吐大 |
| 固定止损 | 通用风控 | 随机游走下零价值；MR 下负价值（K-L） |
| 移动止损 / ATR trailing / Chandelier | 趋势 | 松紧 = 震荡出局率 vs 回吐幅度的权衡；跳空成交价不是止损价 |
| 固定止盈 | MR、短周期 | 砍掉趋势右尾的经典方式 |
| 时间止损（max holding） | MR、事件型 | 把"边际已过期"变成规则 |
| 波动率缩放屏障（k×σ） | 通用、ML 标配 | 跨标的跨 regime 可比 |
| regime 变化退出 | 叠加层 | regime 检测器天然滞后 |
| 信号衰减退出 | 因子/ML | 需要 alpha 半衰期模型 |

### 2.4 三重屏障法（López de Prado）——统一的实现原语

**止盈（上屏障）+ 止损（下屏障）+ 时间（垂直屏障）**，先触及者定标签。它是整个退出分类法的统一语言：

- 固定 TP + 固定 SL + max holding **就是**一个三重屏障
- 移动止损 = 移动的下屏障；ATR/Chandelier = 波动率缩放的移动下屏障
- 反向信号退出 = 无限宽水平屏障 + 信号作为第四条件
- 屏障用 k×σ（波动率倍数）参数化 → 跨标的、跨 regime 可比
- 标签是**路径依赖**的（固定 horizon 收益看不到路径上曾触及止损）
- meta-labeling：主模型定方向，副模型定大小——"何时退出"变成可学习的量

**实现建议：把退出参数化为一个三元组 (TP倍数, SL倍数[可选trailing], 时间屏障)，这一个结构能表达 ~90% 的分类法，且天然兼容回测和 ML 标签。**

### 2.5 分批止盈 / 加仓的证据

- **分批止盈（scaling out）**：数学上是多个全平价位的加权平均——**期望值不可能超过最优单一退出**，它只重塑分布（胜率↑、方差↓、右偏策略均值↓）。合理用途：行为容量（防止交易者整仓逃跑）、流动性、MR 中目标区域不确定时阶梯退出。趋势系统中它专门砍掉扛策略的尾部赢家。
- **金字塔加仓（pyramiding）**：仅在**正偏度（趋势）策略**中提升期望（海龟法则：每 ½ ATR 加一单位，最多 4 单位，整体移动止损保护）；代价是回撤加深，且退出规则必须能机械地平掉整个堆栈。
- 结论：系统化平台应默认**全进全出**；分批只在有明确理由时引入，且必须作为单一复合规则回测，不是免费参数旋钮。

### 2.6 各策略类型的标准退出栈

| 类型 | 标准退出栈 | 避免 |
|---|---|---|
| 趋势/时序动量 | 反向信号 或 ATR/Chandelier trailing（k≈2–3）；无止盈；可选极宽灾难止损；可选金字塔加仓 | 固定止盈、紧固定止损、常规分批止盈 |
| 均值回归 | 均值处固定止盈 + 短时间止损（没回归=前提错了）+ 宽幅灾难止损配小仓位 | 噪声内的紧止损；持有过均值；无组合层面 cap 的补仓 |
| 配对/统计套利 | 价差收敛退出（z→0）+ 协整破裂止损 + OU 半衰期时间止损 + 定期重检协整 | 扛过结构性断裂 |
| 基本面/质量/价值 | 论点驱动退出（估值缺口闭合、因子排名跌出、论点被证伪）；定期再平衡即时间屏障 | 价格锚定止损、止盈 |
| ML 分数 | **三重屏障原生退出**：TP/SL=k×σ，时间屏障=alpha horizon；分数跌破入场阈值即衰减退出。**实盘退出必须与训练屏障一致，否则模型的边际不可迁移** | 固定 horizon 标签；与训练标签不一致的手工止损 |

## 第三部分：多策略组合构建——文献方法

### 3.1 为什么多策略：主动管理基本定律

**Grinold & Kahn：IR ≈ IC × √Breadth**。关键是"独立"——N 个策略两两相关 ρ 时，组合夏普 ≈ `S·√N / √(1+(N−1)ρ)`。ρ=0 时 4 个夏普 0.7 的策略组合出 ~1.4；加一个高相关克隆几乎不加分。

策略逻辑层面的分散（趋势+回归+基本面+宏观门）比标的层面更稳健，因为**不同逻辑在不同 regime 失效**——趋势策略的回撤期恰是 MR 策略的恢复期，组合回撤时长显著缩短。注意：危机中相关性飙升，分散收益要用压力期相关性估计。经验上限：日线+免费数据的单策略夏普 ~1.5 封顶，**组合是主要杠杆**。

### 3.2 策略间资金分配方法

| 方法 | 规则 | 评价 |
|---|---|---|
| 等权 | 1/N | 零估计误差，样本外难被击败（DeMiguel）；忽略波动率 |
| **逆波动率加权** | wᵢ ∝ 1/σᵢ | **小团队甜点位**：简单、稳健、拉平各策略波动贡献 |
| 风险平价 | 各策略对组合 σ 贡献相等 | 标准方法，需稳定协方差估计 |
| 均值-方差 | w* ∝ Σ⁻¹μ | 理论最优但 μ̂ 极噪 → 权重集中不稳；需 Ledoit-Wolf 收缩 |
| 半 Kelly | fᵢ = ½·μᵢ/σᵢ² | 增长最优打折；全 Kelly 在估计误差下接近毁灭 |
| 回撤动态降配 | 回撤越深权重越低 | 模仿 pod 治理；顺周期，需滞后带防抖 |

实践共识：**逆波动率/风险平价 + 每策略波动率目标**是正确默认。

### 3.3 重叠仓位：netting vs 独立 sleeve

- **Sleeve（独立账本）**：每策略独立持仓，重叠即两 sleeve 持对向仓。优点：归因清晰、kill-switch 独立；缺点：对向交易白付双份成本和保证金。
- **Netting（中央账本）**：执行层净额后再下单。省成本但归因模糊、kill-switch 需"解净"。
- **Pod shop 实践（Citadel/Millennium）**：**pod 级 sleeve + 仅执行层 netting**。每 pod 独立资本、风险预算、P&L；Millennium 规则：pod 回撤 ~5% 减半资本、~7.5% 终止。已知脆弱性：pod 间拥挤的共同因子暴露在因子反转时同步亏损——**quant 平台里很多策略可能暗中共享动量因子，这正是要监控因子相关性的原因**。
- 小平台结论：**先 sleeve**（归因和 kill-switch 比保证金节省重要），只在券商执行层 netting，绝不在会计层。

### 3.4 每策略治理栈（规则先于资本设定，机械执行，不容自由裁量）

1. **波动率目标**：每策略跑到固定年化 vol（如 10%），策略间可比，分配=切分风险预算
2. **回撤 kill-switch**：分级降杠杆（-1σ DD 减半，-2σ 或绝对 cap 清盘）
3. **相关性监控**：滚动 60–120 日策略收益相关矩阵 + **因子暴露**监控
4. **alpha 衰减检测**：live 滚动夏普/胜率 vs 回测分布；胜率还在但盈利单缩水 = 拥挤信号；CUSUM、deflated Sharpe
5. **退役标准**：上线前预先注册（如"live 夏普 95% CI 连续 3 个月排除回测下界"）

### 3.5 Regime 路由作为动态分配

HMM（2–4 高斯态 on 收益/波动特征）输出状态概率 πⱼ(t)，按各策略的 regime 条件表现加权：`wᵢ(t) ∝ Σⱼ πⱼ(t)·perfᵢⱼ`。
陷阱：regime 标签跨重拟合不稳定；必须用 filtered 而非 smoothed 概率（否则前视偏差）；转换滞后意味着永远晚切换。**建议作为静态风险平价基础上的倾斜（w = 0.7·w_RP + 0.3·w_regime），不是硬切换。**

## 第四部分：quantlab 的差距清单与建设路线

### 4.1 Feature 缺口总表（新增编号接 AI_QUANT_BOOK_STRATEGY_PLAN.md）

**退出/仓位生命周期（第二部分 × 第一部分 1.3）**

| # | 缺口 | 价值 | 对应文献 |
|---|---|---|---|
| E1 | 分批止盈（multi-tranche exits） | 中——MR 阶梯退出、趋势"卖半留半" | scaling out 是分布重塑工具 |
| E2 | 金字塔加仓 | 中——趋势策略期望增强器 | 海龟法则 |
| E3 | **动态止损：ATR trailing / Chandelier / 保本止损** | **高**——趋势标准退出栈的核心，现有 ATR 止损入场即冻结 | Chandelier (Le Beau/Elder) |
| E4 | regime 条件退出（filter→exit 通道或组合级 gate） | 高——"宏观转空强平"是风控标配 | regime-change exit |

### 4.2 建设顺序（依据：文献的"归因 → 分散度量 → 稳健加权 → 治理 → 动态分配"）

**阶段 A — 组合分析层（1–2 周，纯离线，零风险）**
1. M1：组合净值合成 + 相关矩阵。输入：N 个已有 run 的日收益序列；输出：组合夏普/回撤 vs 各成分、全样本+滚动相关矩阵。这一步立刻回答"我的策略们是真分散还是同一个动量因子的克隆"。
2. M2：逆波动率权重建议。
3. U8：exit_reason 盈亏分布统计——立刻能诊断"趋势策略是否被止盈砍掉右尾"这类错配。
4. U6：组合视图 UI。

**阶段 B — 退出栈增强（2–3 周）**
5. E6：三重屏障统一抽象（ ExecutionConfig 层面重组，向后兼容现有字段）。
6. E3：ATR trailing / Chandelier / 保本止损。
7. E4：组合级 regime 退出通道（接 AI_QUANT_BOOK_STRATEGY_PLAN 的 F6 宏观 gate）。
8. U7：退出配置 UI 按三重屏障重组。

**阶段 C — 多策略一等公民（3–4 周）**
9. M3：portfolio 存储实体 + 组合 run（多策略决策流按权重喂入组合层）。
10. M4：治理配置（kill-switch 阈值 + 衰减告警）。
11. E5：信号强度 sizing（配合 S4 ML 管道）。

**阶段 D — 可选深化**
12. E1/E2：分批止盈与金字塔（引擎改动最大：`_Position` 需支持多 lot）。
13. M5：同账本执行与 netting。
14. M6：HMM regime 路由（研究项目，walk-forward 验证）。

### 4.3 立即可做的零代码验证

在写任何多策略代码之前，可以今天就在 StrategyLab 里做实验验证第二部分的文献结论：

- **趋势 vs 退出实验**：同一个 `sma-crossover`+`adx-trend-filter` 策略跑 4 个变体——(a) 仅信号退出；(b) +2×ATR 止损；(c) +10% 固定止盈；(d) +trailing stop。文献预测：(c) 显著最差（砍右尾），(a)≈(b)≈(d)（Clare et al.：信号退出已内嵌动量退出）。
- **MR vs 退出实验**：`bollinger-reversion` 跑——(a) 仅信号退出；(b) +紧止损；(c) +均值处止盈+短时间止损；(d) 宽止损+小仓位。文献预测：(b) 最差（止损在反弹前触发），(c) 最优。
- 如果回测结果与预测一致，说明引擎和数据的退出语义可信；不一致则是排查 bug 的信号。
